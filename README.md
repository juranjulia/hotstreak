# 密电对决 · 部署和玩法说明

4–8 人、两队对抗的解码猜词游戏。网站由 `server.js`、`index.html`、`words.json` 三个文件组成，零依赖，网页不加载任何境外资源。

## 部署到 Render（和前两个游戏一样）

1. 在 GitHub 新建一个仓库，比如 `midian`，上传这 5 个文件：`server.js`、`index.html`、`words.json`、`package.json`、`README.md`。**`words.json` 是词卡库，一定要一起上传。**
2. 在 Render 点 **+ New → Web Service**，选择这个仓库：
   - Language：**Node**
   - Build Command：`npm install`
   - Start Command：`node server.js`
   - Instance Type：**Free**
3. 部署完成后，日志里 "Available at your primary URL" 后面就是网址。

注意：这是第三个网站，和另外两个共用 Render 每月 750 小时的免费额度（休眠时不计时）。

## 怎么开一局

1. 房主创建房间，点「复制邀请」把链接发给朋友。
2. 每个人自己点「加入红队」或「加入蓝队」。每队 2–4 人。
3. 房主可以打开「计时」，可选 30、60、90 或 120 秒，加密和破译两个阶段都生效：
   - 加密：一队先交提示，另一队的加密者开始倒计时。时间到时，没写完（或含有关键词）的提示记为“（超时）”。
   - 破译 / 拦截：处理每个密码时，破译方和拦截方谁先锁定，另一方就开始倒计时。时间到时自动锁定当前答案，没选完整的部分算猜错。
4. 两队都至少 2 人、所有人都选好队后，房主点「开始游戏」。

## 每一轮

1. **加密：** 每队按顺序轮流派一名加密者。加密者会看到一个只有自己能看到的三位密码，比如 2-3-4，然后按顺序给对应的关键词各写一条提示。提示里不能包含关键词本身。
2. **逐个破译：** 两队都交完提示后，一个一个处理两队的密码。单数轮先处理红队的，双数轮先处理蓝队的。
   - 处理 A 队的密码时，只公开 A 队的提示。A 队队员（加密者除外）破译自己的密码；从第 2 轮起，B 队全员（包括加密者）同时猜这个密码来拦截。
   - 答案全队共享，任何队友都能修改。商量好后由一人点「锁定答案」，**锁定后不能取消**。
   - 双方都锁定后公布这个密码的结果，再反过来处理 B 队的密码。
3. **揭晓：** 本队没猜对，记一个 ✗ 失误标记；猜中对方密码，记一个 ✓ 拦截标记。拦截失败不受罚。提示会自动记进情报记录表。两个密码都处理完后才判定胜负。
4. 所有在线玩家都点「看完了」，进入下一轮。

## 胜负

- 先拿到 2 个拦截标记的队获胜；先吃到 2 个失误标记的队失败。
- 两队在同一轮同时达成，或 8 轮后仍未分出胜负，按“拦截数 − 失误数”比分，高的获胜，相同就是平局。
- 游戏结束时公布两队的关键词和完整的情报记录表。

## 其他

- **队内频道：** 右侧的聊天只有队友能看到。线上讨论请用它，不要用语音，免得被对方听到。
- **掉线：** 刷新后会自动回到房间。如果浏览器丢失了登录信息，用原来的代号重新加入，就能回到原来的座位。
- **结束本局：** 房主可以随时结束本局，回到大厅。
- **词卡库：** `words.json` 里有 15 个主题、350 个词，每局随机抽 8 个。想加词或删词，直接编辑这个文件，按原来的格式写就行。
