# 吉祥物大狂奔 · 部署和玩法说明

2–8 人押注吉祥物赛跑的联机游戏，根据 Hot Streak 的规则和官方卡牌清单汉化制作。网站由 `server.js`、`engine.js`、`index.html` 三个文件组成，零依赖，网页不加载任何境外资源。

## 部署到 Render（和前几个游戏一样）

1. 在 GitHub 新建一个仓库，比如 `kuangben`，上传这 5 个文件：`server.js`、`engine.js`、`index.html`、`package.json`、`README.md`。**`engine.js` 是比赛引擎，一定要一起上传。**
2. 在 Render 点 **+ New → Web Service**，选择这个仓库：
   - Language：**Node**
   - Build Command：`npm install`
   - Start Command：`node server.js`
   - Instance Type：**Free**
3. 部署完成后，日志里 "Available at your primary URL" 后面就是网址。

## 怎么玩

一局 3 场比赛。每人起始 $10，3 场后钱最多的人获胜，并列就共同获胜。房主创建房间后点「复制邀请」，2–8 人到齐后点「开始游戏」。

**每一场：**

1. **选票：** 按蛇形顺序，每人拿 2 张票（2 人局 3 张）；先手每场轮换。每张票可以选稳健面或冒险面。
   - 吉祥物票：所押吉祥物进前三就有钱拿。
   - 附加赌注票：猜这一场会不会发生卡上写的事。
2. **暗中出牌：** 每人从手牌里选 1 张（2 人局 2 张），偷偷加进比赛牌堆，牌堆总共 18 张。右侧会显示牌堆里已经公开的牌。可以在语音里吹牛，但别亮牌。
3. **比赛（轮流翻牌）：** 程序先弃掉 3 张不公开的牌。之后从本场选票先手的玩家开始，按座位顺序轮流翻牌。牌堆背面朝上排成一排，所有人都能看到还剩几张；轮到的人点自己想要的第几张翻开（也可以点「🎲 随便翻一张」），程序自动移动吉祥物：翻牌 1.5 秒，受影响的吉祥物依次移动，每个动作 1 秒。上一张的动画播完后，下一个人才能翻。轮到的人 20 秒内没翻（比如掉线了），程序会随机替他翻一张。牌堆用完时的洗牌和折叠由程序完成。所有人看到的是同一场比赛，还没翻开的牌不会提前发到任何人的浏览器里。
4. **结算：** 按名次和附加赌注的结果拿钱或扣钱，钱不够扣时扣到 0 为止。所有在线玩家都点准备后进入下一场。

**第三场：** 选完票后，每人挑 1 张票双倍结算，赚的翻倍，亏的也翻倍。

## 赛道（横向，终点在右）

- 4 条赛道，从左到右依次是：缓冲区（第 −3 到 −1 格）、起点（第 0 格）、第 1–9 格，跑过第 9 格就算冲线。
- 星星在第 3、6、9 格，终点线后面还有一颗（第 10 格），所以站在第 9 格抽到星星就会直接冲线。
- 白线在第 3、5、7 格前面；第 7–9 格是“冲刺区”。
- 牌堆用完时重新洗牌，赛道后端折叠到下一条白线，还没越过这条线的吉祥物出局。

## 卡牌（按官方清单，共 53 张）

- **每个吉祥物 11 张：** 起跑牌（恢复后 +2，每场必定在牌堆里）、摔倒、掉头、+3、+2、−2、星星、+1/+2/+3 后转弯、恢复后 +1。转弯方向都朝赛道中间：舞狮和招财猫向右转，边牧和青蛙向左转。
- **全体牌 9 张：** 全体恢复后 +2、全体恢复后 +3、全体 +1 ×2、全体 +2 ×2、全体 +3 ×2、全体 −2。所有吉祥物一起动，不会碰撞，也不能冲线。原版的全体牌是绿色的，这里改成紫色 🌀，免得和青蛙的绿色混淆。

## 赔率（经过模拟调整）

| 吉祥物票 | 稳健面 第1/2/3名 | 冒险面 第1/2/3名 |
|---|---|---|
| 第 1 张 | $6 / $4 / $2 | $11 / $1 / $0 |
| 第 2 张 | $5 / $3 / $2 | $9 / $1 / $0 |
| 第 3 张 | $4 / $3 / $1 | $7 / $1 / $0 |

| 附加赌注票 | 稳健面 猜对 / 猜错 | 冒险面 猜对 / 猜错 |
|---|---|---|
| 第 1 张 | +$4 / $0 | +$5 / −$3 |
| 第 2 张 | +$3 / $0 | +$4 / −$3 |
| 第 3 张 | +$2 / $0 | +$3 / −$3 |

想改赔率，可以修改 `server.js` 开头的 `PAY`。想改赛道，可以修改 `engine.js` 开头的 `TRACK`。

## 其他

- **掉线：** 刷新后会自动回到房间。如果浏览器丢失了登录信息，用原来的名字重新加入，就能回到原来的座位。
- **结束本局：** 房主可以随时结束本局，回到大厅。
- **注意：** 如果有人在选票或出牌时掉线，游戏会停在这一步等他回来，暂时没有代选功能。
